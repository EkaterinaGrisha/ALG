## 1. Условие простыми словами

Есть **книга продаж** купца: 53 859 строк, каждая — продажа **одной штуки** товара.
Столбцы: `month` (номер месяца с основания; самый большой номер — декабрь 1571 года),
`name` (товар), `price` (цена продажи).

Нужно составить план прямых продаж на **1572 год**. Для каждого товара и месяца — строка
`товар месяц цена количество`, например `Меч 3 1100 5`. Доля прямых продаж от объёма
рынка растёт на 2 п.п. в месяц: январь 2%, февраль 4%, …, декабрь 24%.

План строится строго по «манускрипту»:

- **сезонность**: прогноз на месяц — только по тому же месяцу прошлых лет;
- только **3 последних года** (1569–1571);
- товары без продаж в 1571 году исключаются;
- **распродажа** — продажа дешевле 50% средней цены товара в этом месяце; так купец больше не будет делать;
- **инфляция** 7% в год;
- **объём рынка за месяц** = средняя цена без распродаж × число **всех** продаж (включая распродажи);
- **прогноз объёма** = среднее за 3 года с учётом инфляции;
- **плановая цена** — наименьшая цена (без распродаж, с инфляцией), которая не меньше 90% цен;
  дробная часть отбрасывается;
- если цену или количество найти нельзя, пишется 0.

Баллы: за каждую верную строку +1, за неверную или повтор −1.

## 2. Краткая теория

### 2.1. Сезонность

**Сезонность** — повторяющиеся колебания по времени года: стройматериалы летом продаются
иначе, чем зимой. Поэтому прогноз на март строится только по мартам прошлых лет, а не по
всем месяцам подряд.

### 2.2. Номер месяца → год и месяц года

Месяцы пронумерованы подряд, а максимальный номер M соответствует декабрю 1571. Тогда для
номера m:

```
сколько месяцев назад:   k = M − m
год:                     1571 − k // 12
месяц года:              12 − k % 12        (12 = декабрь, 1 = январь)
```

`//` — целочисленное деление, `%` — остаток. Здесь M = 89:

| month | год | месяц |
|-------|-----|-------|
| 54 | 1569 | январь |
| 56 | 1569 | март |
| 66 | 1570 | январь |
| 78 | 1571 | январь |
| 89 | 1571 | декабрь |

Для календарного месяца c и года g номер месяца равен `M − (1571 − g)·12 − (12 − c)`.

### 2.3. Инфляция и приведение цен

Цены растут на 7% в год. Значит, цена из года g в ценах 1572 года — это `цена × 1,07^(1572 − g)`.
Для 1571 множитель 1,07, для 1570 — 1,07² = 1,1449, для 1569 — 1,07³ ≈ 1,2250. Без
приведения старые (более низкие) цены занижали бы прогноз.

### 2.4. Распродажи как выбросы

Цены распродаж — это **выбросы**: значения, сильно отличающиеся от остальных. Они
искажают среднюю цену. Манускрипт выкидывает их из расчёта цены, но **не из числа
продаж**: эти покупатели всё равно купили бы по полной цене.

### 2.5. Объём рынка

**Объём рынка** в деньгах = средняя (полная) цена × количество проданных штук. Прогноз на
1572 год — среднее арифметическое объёмов за три года, каждый в ценах 1572 года.

Если в каком-то месяце продаж не было, хотя товар уже продавался (продажи начались раньше),
объём рынка за этот месяц равен **0**, и этот 0 входит в среднее. Именно это и означает
фраза условия «товар считается продающимся с наименьшего месяца, когда по нему была продажа».

### 2.6. Перцентиль

**Перцентиль 90%** — значение, ниже которого лежат 90% данных. Условие даёт точное
определение: «наименьшая цена из множества, которая ≥ 90% цен этого множества».

Сортируем цены по возрастанию, их n штук. Ищем наименьший номер k (с единицы), при котором
k ≥ 0,9·n, то есть `k = ⌈0,9·n⌉`. Ответ — k-я цена. В целых числах: `k = (9n + 9) // 10`.

Пример: 10 цен → k = 9, берём 9-ю по возрастанию. Она не меньше 9 из 10 цен, то есть 90%.

### 2.7. Округления

- Цена: «отбрасывая дробную часть» — это `floor` (округление вниз).
- Количество: нужно продать столько штук, чтобы **достичь** нужной доли, то есть
  `количество × цена ≥ доля × объём`. Это **округление вверх** (`ceil`).

### 2.8. Немного pandas

- `DataFrame` — таблица. `df["price"]` — столбец.
- `df.groupby(["name", "month"])["price"].transform("mean")` — для **каждой строки**
  записывает среднюю цену её группы (товар + месяц). Удобно, чтобы сравнить каждую продажу
  со средней по её месяцу.
- `df[маска]` — выбор строк по условию. Маска — столбец из True/False, например `df["price"] < 100`.

## 3. Суть решения (без кода)

Для каждого товара, проданного в 1571 году, и каждого месяца c = 1…12:

1. Берём этот месяц в 1569, 1570 и 1571 годах.
2. Помечаем распродажи: цена < 50% средней цены товара в этом месяце (средняя по всем продажам месяца).
3. Для каждого года:
   - объём = средняя полная цена × все продажи × 1,07^(1572 − год);
   - цены без распродаж × 1,07^(1572 − год) добавляем в общий список.
4. Прогноз объёма — среднее трёх объёмов (месяц без продаж даёт 0).
5. Плановая цена — 90-й перцентиль общего списка цен, дробная часть отбрасывается.
6. Количество — `⌈2%·c × объём / цена⌉`. Если цену найти нельзя (продаж не было ни в один
   из трёх лет), цена и количество равны 0.

## 4. Логика по шагам с трассировкой

Разберём строку **«Стекло, март»**. Это реальные значения из данных.

**Шаг 1. Распродажи в марте 1569 (month = 56).**

- Продаж 571, средняя цена по всем 86 750,84 → порог 50% = 43 375,42.
- Ниже порога 220 продаж: цены 3 399 … 6 500. Это явно распродажи «для друзей».
- Полных продаж 351: цены 124 999 … 204 620, средняя **138 376,77**.

Видно, зачем нужен порог: распродажи дешевле обычных цен в десятки раз (примерно в 19–60).

**Шаг 2. Объём по годам.**

| Год | month | Всего продаж | Распродаж | Средняя полная цена | Инфляция | Объём |
|-----|-------|--------------|-----------|---------------------|----------|-------|
| 1569 | 56 | 571 | 220 | 138 376,77 | ×1,2250 | 96 794 488 |
| 1570 | 68 | 24 | 0 | 115 676,58 | ×1,1449 | 3 178 515 |
| 1571 | 80 | 0 | 0 | — | ×1,0700 | **0** |

Объём за 1569 год считается по **всем** 571 продажам, хотя средняя цена — только по 351
полной. В марте 1571 года стекло не продавалось, но товар уже был в продаже, поэтому объём 0.

**Шаг 3. Прогноз объёма** = (96 794 488 + 3 178 515 + 0) / 3 = **33 324 334**.

**Шаг 4. Плановая цена.** Цен без распродаж за три года: 351 + 24 = 375, все с инфляцией.
k = ⌈0,9 · 375⌉ = 338 → 338-я по возрастанию цена = 202 119,84 → **202 119**.

**Шаг 5. Количество.** Март — 3-й месяц, доля 6%.
Нужно выручить 0,06 · 33 324 334 = 1 999 460. 1 999 460 / 202 119 = 9,89 → вверх → **10**.

Итоговая строка плана: **`Стекло 3 202119 10`**.

**Особый случай — `Дуб 2 0 0`.** В феврале «Дуб» не продавался ни в одном из трёх лет
(месяцы 55, 67, 79). Цен нет, объём 0, поэтому по примечанию условия пишем 0 и 0.

**Исключённый товар.** «Гвозди» в 1571 году не продавались, поэтому в плане их нет.
Остаётся 8 товаров × 12 месяцев = 96 строк.

### Где условие можно понять по-разному

Мы посчитали, сколько строк ответа меняется при другом прочтении:

| Решение | Почему так | Сколько строк меняет другая трактовка |
|---------|------------|---------------------------------------|
| Количество округляем **вверх** | «найти кол-во продаж **для достижения** доли» | 95 из 96 |
| Перцентиль по **всем транзакциям** | «учитываются только **транзакции** без распродаж» | 74 из 96 |
| Месяц без продаж = **0** в среднем | фраза «товар считается продающимся с наименьшего месяца» | 18 из 96 |

Мораль: в аналитических задачах цена ошибки в одной формулировке огромна. Каждое такое
место стоит явно выписать и обосновать по тексту условия.

## 5. Код

```python
"""D. Торговый план Великого хирфета: расчёт плана продаж на 1572 год по манускрипту.

Запуск: python3 analytics_plan.py data.xlsx > answer.txt
Строка ответа: <товар> <месяц 1..12> <плановая цена> <количество>
"""
import math
import sys
from collections import defaultdict

import pandas as pd

INFL = 1.07          # годовая инфляция 7%
LAST_YEAR = 1571     # максимальный month — декабрь 1571
PLAN_YEAR = 1572
YEARS = (1569, 1570, 1571)   # только 3 последних года


def load(path):
    df = pd.read_excel(path, dtype={"name": str})
    df = df.rename(columns=lambda c: str(c).strip().lower())
    df["name"] = df["name"].astype(str).str.strip()
    df["month"] = df["month"].astype(int)
    df["price"] = df["price"].astype(float)
    last = df["month"].max()                     # декабрь 1571
    df["year"] = LAST_YEAR - (last - df["month"]) // 12
    df["cal"] = 12 - (last - df["month"]) % 12   # 1 = январь, ..., 12 = декабрь
    return df


def plan(df):
    # Распродажа: цена < 50% средней цены товара в этом же месяце (по всем продажам).
    mean_all = df.groupby(["name", "month"])["price"].transform("mean")
    df = df.assign(sale=df["price"] < 0.5 * mean_all)

    start = df.groupby("name")["month"].min()    # товар продаётся с первого месяца продаж
    last = df["month"].max()
    sold_last_year = set(df.loc[df["year"] == LAST_YEAR, "name"])

    rows = []
    for name in sorted(sold_last_year):          # без продаж в 1571 — исключаем
        g = df[df["name"] == name]
        for cal in range(1, 13):
            volumes = []      # расчётный объём рынка по годам (с инфляцией)
            prices = []       # цены без распродаж (с инфляцией)
            for year in YEARS:
                month = last - (LAST_YEAR - year) * 12 - (12 - cal)
                if month < start[name]:
                    continue                     # товар ещё не продавался — год не учитываем
                k = INFL ** (PLAN_YEAR - year)
                cur = g[g["month"] == month]
                full = cur[~cur["sale"]]
                n_all = len(cur)                 # все продажи, включая распродажи
                avg = full["price"].mean() if len(full) else 0.0
                volumes.append(avg * n_all * k)  # нет продаж -> объём 0
                prices.extend((full["price"] * k).tolist())

            volume = sum(volumes) / len(volumes) if volumes else 0.0

            # Плановая цена: наименьшая цена множества, которая >= 90% его цен.
            price = 0
            if prices:
                prices.sort()
                n = len(prices)
                idx = (9 * n + 9) // 10 - 1      # наименьший k: k >= 0.9 * n
                price = int(math.floor(prices[idx] + 1e-9))

            share = 0.02 * cal                   # январь 2%, ..., декабрь 24%
            qty = 0
            if price > 0 and volume > 0:
                qty = int(math.ceil(share * volume / price - 1e-9))
            rows.append((name, cal, price, qty))
    return rows


def main():
    path = sys.argv[1] if len(sys.argv) > 1 else "data.xlsx"
    for name, cal, price, qty in plan(load(path)):
        print(name, cal, price, qty)


if __name__ == "__main__":
    main()
```

## 8. Частые ошибки

1. **Перепутать соответствие месяцев.** Максимальный `month` — декабрь 1571, а не январь.
2. **Использовать все годы** вместо трёх последних или все месяцы вместо одного сезона.
3. **Выкинуть распродажи и из количества продаж.** Они исключаются только из цен.
4. **Считать среднюю для порога распродаж без самих распродаж.** Порог — 50% от средней
   по **всем** продажам месяца.
5. **Забыть инфляцию** или применить её не в ту сторону (делить вместо умножать).
6. **Пропустить месяцы без продаж в среднем** вместо того, чтобы считать их нулём.
7. **Брать перцентиль функцией по умолчанию** (`numpy.percentile` по умолчанию
   интерполирует). Определение в условии — «наименьшая цена из множества, которая ≥ 90% цен».
8. **Округлять количество вниз** — тогда доля не достигается.
9. **Не исключить товары без продаж в 1571 году** или **забыть строки с нулями**, когда цену
   найти нельзя.
