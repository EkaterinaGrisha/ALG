# Задача B. «Подобные цивилизации»

Файл решения: [`similar_civilizations.py`](../similar_civilizations.py). Отправлять можно на
Python 3.13.2 или PyPy: на максимальном тесте около 0,2 с.

---

## 1. Условие простыми словами

Есть `n` цивилизаций (до 10⁹) и `k` характеристик (до 10⁵). Каждой цивилизации
случайно выдаётся строка из `k` битов. Каждый бит — 0 или 1 с вероятностью ½,
независимо от всех остальных, как подбрасывание монетки.

**Схожесть** двух строк — количество позиций, где их биты совпадают. Например,
у `0110` и `0011` совпадают позиции 1 и 3, схожесть 2.

Смотрим на первую цивилизацию и находим, на какую из остальных `n − 1` она похожа
больше всего: берём **максимум** схожести. Это случайная величина, и нужно найти её
**среднее значение** (математическое ожидание). Ответ — дробь, её нужно вывести по
модулю 10⁹ + 7 (что это значит, объяснено ниже).

**Пример 2:** `n = 3, k = 1`. У каждой из трёх цивилизаций один бит, всего
2³ = 8 равновероятных вариантов. В шести из них максимальная схожесть 1, в двух — 0.
Среднее: (6·1 + 2·0) / 8 = 6/8 = 3/4.

## 2. Краткая теория

### 2.1. Вероятность и случайная величина

**Вероятность** события — доля исходов, в которых оно происходит, если все исходы
равновероятны. У монетки два исхода, вероятность «орла» ½.

**Случайная величина** — число, которое зависит от случая. Например, «сколько
выпало орлов из 10 бросков».

**Независимость** — когда результат одного опыта никак не влияет на другой. Броски
разных монеток независимы.

### 2.2. Математическое ожидание

**Математическое ожидание** `E[Y]` — среднее значение случайной величины Y.
Это сумма «значение × вероятность значения» по всем возможным значениям. Для кубика:
`E = (1 + 2 + 3 + 4 + 5 + 6) / 6 = 3,5`.

### 2.3. Сведение к простым величинам

Зафиксируем строку первой цивилизации, какой бы она ни была. Каждый бит строки
другой цивилизации — случайная монетка, и он совпадает с соответствующим битом
первой строки с вероятностью ½, независимо от других битов. Значит:

- схожесть с i-й цивилизацией — это **число совпадений среди k независимых монеток**;
- схожести с разными цивилизациями **независимы друг от друга** (строки генерируются
  отдельно);
- конкретная строка первой цивилизации на ответ не влияет.

Итак, у нас `m = n − 1` независимых одинаково распределённых величин X₁, …, Xₘ,
и нужно найти `E[max(X₁, …, Xₘ)]`.

### 2.4. Биномиальное распределение

Число «успехов» в k независимых бросках монетки распределено по **биномиальному
закону** Bin(k, ½):

```
P(X = j) = C(k, j) / 2^k
```

Здесь `C(k, j)` — **число сочетаний** («цэ из k по j»): сколькими способами можно
выбрать j позиций из k. Формула: `C(k, j) = k! / (j! · (k − j)!)`, где `k! = 1·2·…·k`
(«k факториал»). Всего вариантов строки `2^k`, и в `C(k, j)` из них совпадений ровно j.

Пример `k = 2`: `P(X=0) = 1/4`, `P(X=1) = 2/4`, `P(X=2) = 1/4`.

**Функция распределения** `F(t) = P(X ≤ t)` — вероятность, что значение не больше t:

```
F(t) = (C(k,0) + C(k,1) + … + C(k,t)) / 2^k
```

### 2.5. Максимум независимых величин

`max(X₁, …, Xₘ) ≤ t` ровно тогда, когда **все** `Xᵢ ≤ t`. Вероятности независимых
событий перемножаются, поэтому

```
P(max ≤ t) = F(t)^m,       P(max > t) = 1 − F(t)^m
```

### 2.6. Ожидание через «хвосты»

Для величины Y, принимающей значения 0, 1, …, K, верно:

```
E[Y] = P(Y > 0) + P(Y > 1) + … + P(Y > K−1)
```

Почему: если Y = 3, то события «Y > 0», «Y > 1», «Y > 2» выполнены, а «Y > 3» и далее — нет.
Значит, в правой сумме этот исход учтён ровно 3 раза, то есть столько, сколько равно Y.
Это верно для каждого исхода, поэтому суммы совпадают.

Подставляем Y = max (значения от 0 до k):

```
E[max] = Σ_{t=0}^{k−1} (1 − F(t)^m) = k − Σ_{t=0}^{k−1} F(t)^m
```

Это и есть итоговая формула.

### 2.7. Ответ «по модулю»: обратный элемент

Ответ — дробь P/Q, а дробные числа в компьютере неточны. Поэтому просят вывести
`P · Q⁻¹ mod p`, где p = 10⁹ + 7 — простое число.

- `a mod p` — остаток от деления a на p.
- **Обратный элемент** `Q⁻¹` по модулю p — такое число y, что `Q · y mod p = 1`. Оно
  играет роль «деления на Q». Например, обратное к 4 — это 250000002, потому что
  `4 · 250000002 = 1000000008 = 1·(10⁹ + 7) + 1`.
- **Малая теорема Ферма** даёт способ найти обратный элемент: для простого p и Q,
  не делящегося на p, верно `Q^(p−1) mod p = 1`, значит `Q⁻¹ = Q^(p−2) mod p`.
- Дробь 3/4 записывается как `3 · 250000002 mod p = 750000006` — это ответ примера 2.

Все действия (сложение, умножение, «деление» через обратный элемент) по модулю
согласованы с обычной арифметикой дробей. Поэтому можно вычислять формулу прямо
по модулю, и получится ровно нужное `P · Q⁻¹ mod p`.

### 2.8. Быстрое возведение в степень

`pow(a, e, p)` в Python считает `aᵉ mod p` за `O(log e)` умножений. Степень раскладывается
по двоичной записи: `a¹³ = a⁸ · a⁴ · a¹`, а `a², a⁴, a⁸` получаются последовательным
возведением в квадрат. Поэтому даже `e = 10⁹` — это всего около 30 умножений.

### 2.9. Факториалы и обратные факториалы

Чтобы быстро считать `C(k, t) mod p`, заранее вычисляют:

- `fact[i] = i! mod p` по формуле `fact[i] = fact[i−1] · i`;
- `inv_fact[i] = (i!)⁻¹ mod p`. Сначала одна степень: `inv_fact[k] = fact[k]^(p−2)`.
  Потом остальные идут в обратную сторону: `inv_fact[i−1] = inv_fact[i] · i`, так как
  `1/(i−1)! = i / i!`.

Тогда `C(k, t) = fact[k] · inv_fact[t] · inv_fact[k−t] mod p`, и каждый коэффициент
считается за `O(1)`.

## 3. Суть решения (без кода)

1. Схожести с остальными `m = n − 1` цивилизациями — независимые величины Bin(k, ½).
2. `E[max] = k − Σ_{t=0}^{k−1} F(t)^m`, где `F(t)` — накопленная сумма биномиальных
   коэффициентов, делённая на `2^k`.
3. Считаем всё по модулю 10⁹ + 7: коэффициенты через факториалы, деление на `2^k`
   через обратный элемент, степень m через быстрое возведение.

## 4. Логика по шагам с трассировкой

### Пример 2: n = 3, k = 1

- `m = 2`.
- `t = 0`: `C(1,0) = 1`, `F(0) = 1/2`, `F(0)² = 1/4`.
- `E = 1 − 1/4 = 3/4`, по модулю `3 · 4⁻¹ = 750000006`. Это ответ из условия.

### Пример 1: n = 2, k = 10

- `m = 1`: максимум одной величины — это она сама. Ответ — среднее число совпадений
  среди 10 монеток, то есть 10 · ½ = **5**.
- Формула даёт то же: `10 − Σ F(t)` по t = 0..9 — это и есть `E[X]` по формуле «хвостов».

### Подробный пример: n = 3, k = 2

`m = 2`. Распределение одной схожести: `P(0) = 1/4, P(1) = 2/4, P(2) = 1/4`.

| t | Σ C(2, j) для j ≤ t | F(t) | F(t)² | F(t)² по модулю |
|---|---------------------|------|-------|-----------------|
| 0 | 1 | 1/4 | 1/16 | 562500004 |
| 1 | 1 + 2 = 3 | 3/4 | 9/16 | 62500001 |

`E = 2 − (1/16 + 9/16) = 22/16 = 11/8`, по модулю **375000004**.

Проверим «в лоб» через распределение максимума:

- `P(max = 0) = F(0)² = 1/16`;
- `P(max = 1) = F(1)² − F(0)² = 8/16`;
- `P(max = 2) = 1 − F(1)² = 7/16`.

`E = 0·1/16 + 1·8/16 + 2·7/16 = 22/16`, совпадает.

Как проверить модульное число: `16 · 562500004 = 9000000064 = 9·(10⁹+7) + 1`,
то есть 562500004 действительно «одна шестнадцатая».

## 5. Код

```python
import sys

MOD = 10 ** 9 + 7


def main():
    n, k = map(int, sys.stdin.read().split())
    m = n - 1

    fact = [1] * (k + 1)
    for i in range(1, k + 1):
        fact[i] = fact[i - 1] * i % MOD
    inv_fact = [1] * (k + 1)
    inv_fact[k] = pow(fact[k], MOD - 2, MOD)
    for i in range(k, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    # При фиксированной ch1 схожести с остальными — m независимых Bin(k, 1/2).
    # E[max] = sum_{t=0}^{k-1} P(max > t) = k - sum_{t=0}^{k-1} F(t)^m,
    # где F(t) = P(X <= t) = (C(k,0) + ... + C(k,t)) / 2^k.
    inv_2k = pow(pow(2, k, MOD), MOD - 2, MOD)
    fk = fact[k]
    prefix = 0
    total = 0
    for t in range(k):
        prefix = (prefix + fk * inv_fact[t] % MOD * inv_fact[k - t]) % MOD
        total += pow(prefix * inv_2k % MOD, m, MOD)

    print((k - total) % MOD)


main()
```

## 6. Построчный разбор кода

```python
MOD = 10 ** 9 + 7
```

- Модуль из условия. Это простое число, поэтому работает теорема Ферма.

```python
n, k = map(int, sys.stdin.read().split())
m = n - 1
```

- Читаем два числа. `m` — с каким количеством цивилизаций сравниваем первую.

```python
fact = [1] * (k + 1)
for i in range(1, k + 1):
    fact[i] = fact[i - 1] * i % MOD
```

- `fact[i] = i! mod p`. Остаток берём на каждом шаге, чтобы числа не росли.

```python
inv_fact = [1] * (k + 1)
inv_fact[k] = pow(fact[k], MOD - 2, MOD)
for i in range(k, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD
```

- `inv_fact[k]` — обратный элемент к `k!` по теореме Ферма (одно быстрое возведение в степень).
- Остальные считаются за одно умножение каждый: `1/(i−1)! = i · 1/i!`.

```python
inv_2k = pow(pow(2, k, MOD), MOD - 2, MOD)
fk = fact[k]
prefix = 0
total = 0
```

- `inv_2k` — это `(2^k)⁻¹`, то есть «деление на 2^k».
- `fk = k!` вынесено в переменную, чтобы не обращаться к списку каждый раз.
- `prefix` — накопленная сумма `C(k,0) + … + C(k,t)` по модулю.
- `total` — накопленная сумма `F(t)^m`.

```python
for t in range(k):
    prefix = (prefix + fk * inv_fact[t] % MOD * inv_fact[k - t]) % MOD
    total += pow(prefix * inv_2k % MOD, m, MOD)
```

- Перебираем t от 0 до k − 1.
- Прибавляем к `prefix` очередной `C(k, t) = k! · (t!)⁻¹ · ((k−t)!)⁻¹`.
- `prefix * inv_2k % MOD` — это `F(t)` по модулю. `pow(..., m, MOD)` возводит его в степень
  m за `O(log m)`.
- `total` по модулю не сокращаем: он не больше k·p ≈ 10¹⁴, Python справится, а в конце
  всё равно берём остаток.

```python
print((k - total) % MOD)
```

- Итог `k − Σ F(t)^m` по модулю. Если разность отрицательна, оператор `%` в Python
  всё равно вернёт число от 0 до p − 1.

## 7. Сложность

- **Время:** `O(k)` на факториалы и `O(k · log n)` на возведения в степень. При k = 10⁵
  и n = 10⁹ это около 3·10⁶ умножений, примерно 0,2 с.
- **Память:** `O(k)` на два массива факториалов.

## 8. Частые ошибки

1. **Считать в дробях с плавающей точкой** (`float`). Теряется точность, а ответ всё равно
   нужен по модулю.
2. **Перебирать цивилизации.** n до 10⁹, поэтому нужен `pow(x, n−1, p)`, а не цикл.
3. **Путать m = n − 1 и n.** Первая цивилизация сама с собой не сравнивается.
4. **Неверные границы суммы.** Суммировать нужно по t от 0 до **k − 1** (`P(max > t)`
   при t = k равна нулю). Если взять t до k, в сумму попадёт лишнее слагаемое
   `F(k)^m = 1`, и ответ окажется на единицу меньше правильного.
5. **«Делить» по модулю обычным делением.** `a / b` не работает в остатках; нужно
   умножать на обратный элемент `b^(p−2)`.
6. **Считать `C(k, t)` через `math.comb` в цикле.** Это огромные точные числа, и по
   времени получится очень медленно. Факториалы по модулю считаются за `O(1)` на коэффициент.
7. **`pow` без третьего аргумента.** `pow(x, m)` при m = 10⁹ попытается построить
   гигантское число. Нужно `pow(x, m, MOD)`.
