# Задача A. «Статуи острова Пасхи»

Файл решения: [`easter_island.py`](../easter_island.py). Отправлять можно на Python 3.13.2
или PyPy: самый тяжёлый тест идёт около 0,2 с.

---

## 1. Условие простыми словами

Остров — квадратная таблица `n × n`. Строки пронумерованы от 1 до n сверху вниз,
столбцы — от 1 до n слева направо. На острове `n` статуй, статуя `i` стоит в клетке
(строка `rᵢ`, столбец `cᵢ`). В одной клетке могут стоять несколько статуй.

За один день можно передвинуть **одну** статую в **соседнюю по стороне** клетку:
вверх, вниз, влево или вправо.

Нужно за наименьшее число дней добиться того, чтобы все статуи стояли **в разных
строках** и **в разных столбцах**, то есть никакие две не делили строку или столбец.

**Пример 1:** статуи в клетках (1, 2), (1, 3), (3, 3), ответ 3. Можно поставить
их в (1, 1), (2, 2), (3, 3):

- первая сдвигается на 1 клетку влево;
- вторая — на 1 вниз и на 1 влево;
- третья стоит на месте.

Итого 1 + 2 + 0 = 3 дня.

## 2. Краткая теория

### 2.1. Манхэттенское расстояние

Чтобы перевести статую из клетки (r, c) в клетку (r', c') ходами «на соседнюю
клетку», нужно минимум `|r − r'| + |c − c'|` ходов. Каждый ход меняет на единицу либо
строку, либо столбец, а меньше ходов не бывает: строку нужно сдвинуть на `|r − r'|`,
столбец — на `|c − c'|`. Такое расстояние называют **манхэттенским**, как путь по
кварталам Манхэттена, где можно ходить только вдоль улиц.

### 2.2. Перестановка

**Перестановка** чисел 1..n — это они же, записанные в каком-то порядке, каждое ровно
один раз. Например, `3 1 2`. Раз статуй n, а строк тоже n, и все строки должны быть
разными, то итоговые номера строк — это перестановка 1..n: каждая строка занята
ровно одной статуей. То же верно для столбцов.

### 2.3. Строки и столбцы независимы

Общая стоимость — сумма по статуям `|Δстроки| + |Δстолбца|`, то есть
`(сумма сдвигов по строкам) + (сумма сдвигов по столбцам)`.

Требование к строкам — «все строки разные», к столбцам — «все столбцы разные». Эти
требования друг с другом не связаны: можно как угодно распределить статуи по
строкам и, **отдельно**, как угодно распределить их по столбцам. Статуи друг другу
не мешают (они могут временно стоять в одной клетке). Значит, задача распадается
на две **одинаковые одномерные** задачи: одну для строк, другую для столбцов.

### 2.4. Одномерная задача: числа на прямой

Есть n чисел (например, номера строк статуй). Каждое нужно превратить в одно из
чисел 1, 2, …, n, причём все результаты разные, а сумма `|сдвигов|` должна быть
минимальной.

**Решение: отсортировать числа по возрастанию и отправить самое маленькое в 1,
следующее в 2, и так далее, самое большое — в n.**

Почему так оптимально. Возьмём два числа `x ≤ y` и две цели `p ≤ q`. Есть два
способа их сопоставить:

- «по порядку»: x → p и y → q;
- «крест-накрест»: x → q и y → p.

Нарисуйте две стрелки на числовой прямой: при способе «крест-накрест» они
пересекаются. Можно проверить все случаи расположения, и всегда выходит

```
|x − p| + |y − q|  ≤  |x − q| + |y − p|
```

Например, `x = 1, y = 5, p = 2, q = 3`: по порядку `1 + 2 = 3`, крест-накрест `2 + 3 = 5`.

Значит, любое распределение с «перекрёстком» можно улучшить или хотя бы не ухудшить,
поменяв двум числам цели местами. Будем повторять такие обмены, пока перекрёстки не
кончатся. В итоге получится распределение «по порядку», и оно не хуже любого
другого. Такой способ доказательства называется **аргументом обмена** (exchange argument).

### 2.5. Сортировка

**Сортировка** — расстановка чисел по возрастанию. Встроенная `sorted(...)` в Python
работает за `O(n log n)`: для n = 10⁵ это доли секунды.

## 3. Суть решения (без кода)

1. Выписываем номера строк всех статуй и сортируем.
2. Ответ по строкам: `Σ |r_sorted[i] − i|` для i = 1..n (i-я по величине строка
   отправляется в строку i).
3. То же самое для столбцов.
4. Ответ — сумма двух чисел.

## 4. Логика по шагам с трассировкой

Второй пример: 5 статуй в клетках (3, 2), (5, 4), (1, 3), (2, 3), (1, 2).

**Строки.** Исходные: `3, 5, 1, 2, 1`. После сортировки: `1, 1, 2, 3, 5`.

| i (цель) | 1 | 2 | 3 | 4 | 5 |
|----------|---|---|---|---|---|
| строка (отсортированная) | 1 | 1 | 2 | 3 | 5 |
| сдвиг \|строка − i\| | 0 | 1 | 1 | 1 | 0 |

Сумма по строкам: **3**.

**Столбцы.** Исходные: `2, 4, 3, 3, 2`. После сортировки: `2, 2, 3, 3, 4`.

| i (цель) | 1 | 2 | 3 | 4 | 5 |
|----------|---|---|---|---|---|
| столбец (отсортированный) | 2 | 2 | 3 | 3 | 4 |
| сдвиг \|столбец − i\| | 1 | 0 | 0 | 1 | 1 |

Сумма по столбцам: **3**. Ответ 3 + 3 = **6**, совпадает с условием.

**Первый пример:** строки `1, 1, 3` идут в `1, 2, 3` со сдвигами `0 + 1 + 0 = 1`;
столбцы `2, 3, 3` идут в `1, 2, 3` со сдвигами `1 + 1 + 0 = 2`. Ответ 3.

Обратите внимание: какая конкретно статуя куда пойдёт, считать не нужно. Достаточно
знать сумму сдвигов. Распределение по строкам и по столбцам делается отдельно, а
вместе они дают каждой статуе свою клетку.

## 5. Код

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    # Строки и столбцы двигаются независимо: каждую координату нужно
    # превратить в перестановку 1..n. Оптимально сопоставить отсортированные
    # координаты с 1, 2, ..., n по порядку.
    r = sorted(map(int, data[1:2 * n + 1:2]))
    c = sorted(map(int, data[2:2 * n + 2:2]))
    ans = 0
    for i in range(n):
        ans += abs(r[i] - i - 1) + abs(c[i] - i - 1)
    print(ans)


main()
```

## 6. Построчный разбор кода

```python
data = sys.stdin.buffer.read().split()
n = int(data[0])
```

- Читаем весь ввод и режем на токены. Первый токен — число статуй `n`.
- Дальше токены идут парами: `r₁ c₁ r₂ c₂ …`.

```python
r = sorted(map(int, data[1:2 * n + 1:2]))
```

- `data[1:2 * n + 1:2]` — **срез с шагом**. Запись `[старт:стоп:шаг]` значит «начать
  с индекса старт, идти до индекса стоп (не включая его), каждый раз прыгая на шаг».
  Здесь берутся элементы с индексами 1, 3, 5, … — это все номера строк.
- `map(int, ...)` превращает их в числа, `sorted(...)` возвращает новый
  отсортированный список.

```python
c = sorted(map(int, data[2:2 * n + 2:2]))
```

- То же для столбцов: индексы 2, 4, 6, …

```python
ans = 0
for i in range(n):
    ans += abs(r[i] - i - 1) + abs(c[i] - i - 1)
print(ans)
```

- В Python индексы начинаются с 0, а номера строк — с 1. Поэтому i-й по порядку
  (с нуля) элемент отправляется в строку `i + 1`, и сдвиг равен `|r[i] − (i + 1)|`.
- `abs(...)` — модуль числа (абсолютное значение).
- Складываем сдвиги и для строк, и для столбцов, затем печатаем.

## 7. Сложность

- **Время:** `O(n log n)` на две сортировки плюс `O(n)` на суммирование. При n = 10⁵
  около 0,2 с.
- **Память:** `O(n)`.

Ответ может достигать ~10¹⁰: все статуи в одном углу, тогда сдвиг по каждой оси
`0 + 1 + … + (n−1) ≈ n²/2`. В C++ нужен `long long`.

## 8. Частые ошибки

1. **Моделировать движения или запускать поиск в ширину (BFS) по состояниям.**
   Число состояний астрономическое. Задача решается формулой.
2. **Думать, что статуи мешают друг другу.** По условию в одной клетке может быть
   несколько статуй, поэтому движения независимы.
3. **Пытаться согласовать строку и столбец одной статуи.** Не нужно: распределения
   по строкам и по столбцам выбираются независимо.
4. **Сопоставлять без сортировки** (например, статую i в строку i). Это даёт
   неоптимальный ответ: правильно только «по порядку величины».
5. **Ошибка на единицу.** Цели — это 1..n, а индексы в коде — 0..n−1. Отсюда `i + 1`.
6. **Переполнение в C++/Java.** Сумма может быть около 10¹⁰.
